# GameDock

GameDock запускает локальные серверы Minecraft Java и даёт друзьям подключиться к ним по приглашению. Приложение написано на Go, Wails и React для Windows x64. Исходный код сгенерирован при помощи ИИ и доработан в ходе тестирования.

## Скачать

Готовые Windows-сборки находятся в [Releases](../../releases/latest).

| Файл | Назначение |
| --- | --- |
| `GameDock-Server.exe` | Управление Minecraft-серверами, консоль и создание комнат |
| `GameDock-Connect.exe` | Вход в комнаты по приглашению. Подходит для отправки друзьям |

Для интерфейса нужен Microsoft Edge WebView2 Runtime. Владельцу сервера также нужны совместимая Java и файлы Minecraft-сервера. Для NeoForge укажите файл аргументов `win_args.txt` из установленного сервера.

## Игра с друзьями

1. В полной версии добавьте сервер, укажите папку мира, Java и способ запуска. Прочтите Minecraft EULA и примите её в `eula.txt`, если согласны.
2. Запустите Minecraft и дождитесь `Done` в консоли.
3. В разделе **Комнаты** установите EasyTier, создайте комнату для сервера и подключите её. Скопируйте приглашение.
4. Друг открывает Connect, устанавливает EasyTier и добавляет комнату по приглашению. После подключения он вводит в Minecraft адрес из карточки, например `127.0.0.1:25566`.

Приглашение содержит ключ комнаты. Отправляйте его участникам приватно. EasyTier использует начальные узлы для обнаружения участников. Прямой режим зависит от сети обеих сторон. Если комната ждёт участников, проверьте доступность начальных узлов и совпадение их списка на обоих компьютерах. Локальный ответ TCP-порта Connect сам по себе не подтверждает, что Minecraft доступен через туннель.

## Сборка из исходников

Установите Go согласно `go.mod`, Node.js с npm и WebView2. Из корня репозитория выполните `build-both.cmd`. Скрипт соберёт интерфейс и обе редакции в `build/bin`. Редакция Connect использует тег Go `client`, который исключает серверный модуль.

Для запуска тестов после сборки интерфейса выполните `go test ./...` и `go test -tags client .`. Нативный тест EasyTier использует локальный официальный архив и включается отдельно.
